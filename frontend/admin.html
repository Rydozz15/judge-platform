Importar Preguntas y Respuestas (CSV)

El CSV debe contener una columna cabecera llamada "pregunta" y columnas adicionales para cada variante (ej. naive, rag, professional). Opcionalmente puede tener is_calibration.

Importar Rúbrica desde CSV

El CSV debe contener cabeceras: "nombre", "descripcion" (o descripcion_general), "min_score", "max_score", y "peso". Para descripciones de puntaje específicas, agregue columnas como descripcion_1, descripcion_2, etc.
